# HomeWork

Учебный репозиторий с домашними работами по `React`. Здесь собрана моя практика от самых первых компонентов и передачи `props` до маршрутизации, `Redux Toolkit`, работы с состоянием, формами, каталогом товаров и более крупной структуры приложения.

![Главный баннер](./HW8/public/img/men_main.svg)

## Что я изучал

В этом репозитории я последовательно отрабатывал:

- создание и переиспользование React-компонентов;
- передачу данных через `props`;
- работу со списками и пользовательским интерфейсом;
- `React Router` и навигацию между страницами;
- `Redux Toolkit` и глобальное состояние;
- `thunk` и организацию логики приложения;
- `Sass`, структуру стилей и сборку на `Vite`;
- проектирование более крупного интернет-магазина на React.

## Структура домашних работ

### HW1. Компоненты и props

Первая работа посвящена базовой структуре React-приложения. Здесь я учился создавать компоненты и передавать в них данные через `props`, чтобы переиспользовать один и тот же шаблон с разным содержимым.

Что было изучено:

- создание функциональных компонентов;
- импорт компонентов в `App`;
- передача `title` и `message` через `props`;
- базовая стилизация компонентов.

Папка проекта: [`HW1`](./HW1)

### HW2. Списки комментариев

Во второй работе я собрал компонент списка комментариев. Здесь уже появилась практика отображения набора данных и композиции интерфейса из нескольких частей.

Что было изучено:

- рендер списка элементов;
- разбиение интерфейса на компоненты;
- организация структуры проекта;
- работа с CSS для отдельных блоков.

Папка проекта: [`HW2`](./HW2)

### HW3. Конвертер температуры и список задач

В этой домашней работе я делал сразу несколько интерфейсных задач: конвертер температуры и список дел. Это была практика локального состояния, обработки действий пользователя и построения интерактивного UI.

Что было изучено:

- работа с формами и вводом данных;
- обновление состояния компонента;
- интерактивные элементы;
- подключение библиотеки `MUI`.

Папка проекта: [`HW3`](./HW3)

### HW4. Маршрутизация в React

Здесь я перешел на `Vite` и начал изучать маршрутизацию. В проекте реализованы страницы `Home` и `About` с навигацией через `react-router-dom`.

Что было изучено:

- настройка проекта на `Vite`;
- маршруты через `BrowserRouter`, `Routes` и `Route`;
- переход между страницами;
- разделение приложения на страницы.

Папка проекта: [`HW4`](./HW4)

### HW5. Переключение темы через Redux Toolkit

Эта работа посвящена глобальному состоянию. Я реализовал переключение темы сайта через `Redux Toolkit` и связал состояние со всем интерфейсом.

Что было изучено:

- создание `slice`;
- настройка `store`;
- использование `useSelector` и `useDispatch`;
- обновление интерфейса на основе глобального состояния.

Папка проекта: [`HW5`](./HW5)

### HW6. Каталог продуктов

В шестой работе я собрал каталог продуктов с возможностью добавления и редактирования. Это уже более прикладной сценарий, где `Redux` используется для управления списком сущностей.

Что было изучено:

- CRUD-логика для списка товаров;
- хранение данных в `Redux`;
- формы добавления и редактирования;
- разбиение логики по компонентам и `slice`.

Папка проекта: [`HW6`](./HW6)

### HW7. Список задач с Redux

Седьмая работа продолжила тему управления состоянием, но уже на примере задач. Здесь использовались `Redux Toolkit` и `redux-thunk`.

Что было изучено:

- хранение задач в глобальном состоянии;
- организация данных и редьюсеров;
- работа с `thunk`;
- построение масштабируемой структуры проекта.

Папка проекта: [`HW7`](./HW7)

### HW8. Интернет-магазин

Самая крупная работа в репозитории. Здесь я собрал полноценное многостраничное приложение интернет-магазина с каталогом, карточкой товара, корзиной, регистрацией, роутингом, `Redux` и `Sass`.

![Категории магазина](./HW8/public/img/categories2_men.svg)

Что было изучено:

- многостраничная структура приложения;
- маршруты для главной страницы, каталога, корзины, регистрации и карточки товара;
- работа с корзиной через `Redux Toolkit`;
- пагинация, фильтрация и отображение товаров;
- организация стилей через `SCSS`;
- композиция большого проекта из компонентов, страниц и общих блоков.

Папка проекта: [`HW8`](./HW8)
